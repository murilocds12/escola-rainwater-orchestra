Sistema Automatizado de Aproveitamento de Água da Chuva

“Água da chuva hoje, um futuro melhor amanhã!”

Uma maquete que capta a chuva, mede o nível com sensor e usa Arduino + energia solar para bombear a água automaticamente até a caixa-d'água.

▶ Ver o painel ao vivo
✔ Automação com Arduino
✔ Energia 100% solar
✔ Sensor de nível em tempo real
✔ Baixo custo e replicável
🚱

O problema

Muita água tratada é desperdiçada em tarefas que não exigem água potável, enquanto a chuva escorre pelos telhados e vai embora sem uso.

🌧️

A solução

Captar a chuva pela calha, armazená-la e, com sensor e Arduino alimentados por energia solar, bombeá-la sozinha para a caixa-d'água.

    // Sistema Automatizado de Aproveitamento de Água da Chuva
// Escola Técnica Adélia – Projeto Integrador 2026
const int PINO_NIVEL   = A0;  // sensor de nível (analógico)
const int PINO_BOMBA   = 7;   // relé da bomba
const int PINO_BATERIA = A1;  // divisor de tensão da bateria
const int ACIONAMENTO  = 80;  // % para ligar a bomba
const int MINIMO       = 10;  // % para desligar a bomba

bool bomba = false;

void setup() {
  Serial.begin(9600);
  pinMode(PINO_BOMBA, OUTPUT);
  digitalWrite(PINO_BOMBA, LOW);
}

void loop() {
  int nivel   = map(analogRead(PINO_NIVEL), 0, 1023, 0, 100);
  int bateria = map(analogRead(PINO_BATERIA), 600, 860, 0, 100);
  bateria = constrain(bateria, 0, 100);
  bool sensor = nivel >= ACIONAMENTO;

  if (bateria == 0)          bomba = false;  // sem energia: para
  else if (sensor)           bomba = true;   // nível atingido: liga
  else if (nivel <= MINIMO)  bomba = false;  // esvaziou: desliga

  digitalWrite(PINO_BOMBA, bomba ? HIGH : LOW);

  Serial.print("nivel=");    Serial.print(nivel);
  Serial.print(";sensor=");  Serial.print(sensor ? 1 : 0);
  Serial.print(";bomba=");   Serial.print(bomba ? 1 : 0);
  Serial.print(";bateria="); Serial.println(bateria);
  delay(500);
}
    Funcionamento

    Como funciona

    Dois fluxos trabalham juntos: a energia do sol alimenta a eletrônica, e a eletrônica movimenta a água.

    ⚡ Fluxo de energia

    ☀ Placa solar→ 🎛 Controlador de carga→ 🔋 Baterias→ 🧠 Arduino · 📡 Sensor · ⚙ Bomba

    💧 Fluxo da água

    🌧 Chuva→ 🏠 Calha→ 🛢 Reservatório inicial→ 📡 Sensor de nível→ 🧠 Arduino→ ⚙ Bomba→ 〰 Mangueira→ 🏗 Caixa-d'água

    Passo a passo

    1. A chuva cai no telhado e escorre pela calha.
    2. A água é armazenada no reservatório inicial.
    3. O sensor de nível monitora a altura da água.
    4. Ao atingir o nível definido, o sensor avisa o Arduino.
    5. O Arduino liga a bomba, que envia a água pela mangueira.
    6. A caixa-d'água enche; quando o reservatório esvazia, a bomba desliga.

    Lógica de controle

    SE sensor detectar o nível
      → Arduino LIGA a bomba
    SE a água baixar
      → Arduino DESLIGA a bomba
    SE bateria = 0%
      → sistema PARA
